Términos y Condiciones de Servicio

Estos términos aplican por igual al Landing Page, a la Web Application y a la API RESTful de Medical SmartBox.

1. Aceptación de los términos

Al acceder al Landing Page, registrarte o utilizar la Web Application de Medical SmartBox, aceptas estos Términos y Condiciones. Si no estás de acuerdo, no debes utilizar la plataforma.

2. Descripción del servicio

Medical SmartBox es una plataforma de monitoreo y trazabilidad para el transporte de productos médicos, compuesta por un sitio web estático, una Web Application y dispositivos SmartBox conectados.

3. Cuentas y acceso

  1. El acceso a la Web Application requiere una cuenta asignada por tu organización.
  2. Eres responsable de mantener la confidencialidad de tus credenciales.
  3. Medical SmartBox puede suspender cuentas ante un uso indebido de la plataforma.

4. Datos y privacidad

Los datos capturados por los dispositivos SmartBox (ubicación, temperatura, peso y estado del envío) se utilizan exclusivamente para brindar el servicio de monitoreo y trazabilidad contratado.

5. Disponibilidad del servicio

Medical SmartBox procura mantener la plataforma disponible de forma continua, pero puede realizar mantenimientos programados que se comunicarán con antelación cuando sea posible.

6. Propiedad intelectual

El software, las marcas y el contenido del Landing Page y la Web Application pertenecen a Medical SmartBox o a sus licenciantes.

7. Modificaciones

Estos términos pueden actualizarse; los cambios relevantes se notificarán a través del Landing Page o de la Web Application.

8. Contacto

Para consultas sobre estos términos, escribe al equipo de Medical SmartBox desde el formulario de contacto de la plataforma.

Política de Privacidad

Esta política explica qué datos recopila Medical SmartBox y cómo se usan, tanto en el Landing Page como en la Web Application y los dispositivos SmartBox.

1. Datos que recopilamos

Recopilamos datos de cuenta (nombre, correo corporativo y organización), datos de uso de la Web Application y datos operativos de cada transporte registrado en la plataforma.

2. Datos de los dispositivos SmartBox

Cada SmartBox transmite ubicación, temperatura, peso, apertura de puerta, batería y estado del equipo mientras dura el transporte. Estos datos se asocian al envío, no a una persona en particular.

3. Cómo usamos los datos

  1. Para mostrar el estado y la ubicación de cada transporte en tiempo real.
  2. Para generar alertas cuando una lectura se sale del rango esperado.
  3. Para construir el historial y la trazabilidad de cada envío.

4. Con quién compartimos información

Los datos de un transporte son visibles únicamente para la organización que lo gestiona y, cuando corresponde, para el centro de salud receptor. Medical SmartBox no vende datos a terceros.

5. Seguridad de la información

El acceso a la Web Application requiere una cuenta asignada por la organización, y las lecturas de cada SmartBox viajan cifradas desde el dispositivo hasta la plataforma.

6. Conservación de datos

El historial de cada transporte se conserva mientras la cuenta de la organización esté activa, o el tiempo que exija la normativa aplicable al tipo de producto transportado.

7. Derechos del usuario

Cualquier integrante de una organización con acceso a la plataforma puede solicitar corregir sus datos de cuenta o consultar qué información se ha registrado sobre su actividad.

8. Cambios y contacto

Esta política puede actualizarse; los cambios relevantes se comunicarán a través del Landing Page o de la Web Application. Para consultas, escribe al equipo de Medical SmartBox desde el formulario de contacto.
